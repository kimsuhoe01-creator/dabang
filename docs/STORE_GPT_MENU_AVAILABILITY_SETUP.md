# 매장 GPT 품절 관리 — 한 번만 설정

서버 기능은 2026-09-04에 배포 완료했다. 남은 작업은 기존 매장 GPT의 작업 스키마를 한 번 갱신하고, 매장 직원이 별도 ChatGPT 계정으로 이 GPT를 열 수 있게 공유하는 것이다.

## 사장님이 할 일

1. 매장에서 쓸 태블릿이나 PC의 ChatGPT에 **매장 직원용 계정**으로 로그인한다. 개인 계정 비밀번호를 직원과 공유하지 않는다.
2. 사장님 개인 계정의 매장 GPT 편집 화면에서 직원을 초대하거나, 매장 직원이 사용할 수 있는 방식으로 이 GPT를 공유한다.
3. GPT의 `작업(Actions)`에서 아래 스키마 주소를 다시 불러와 저장한다.

   `https://dabang-cukcuk-order-api.kimsuhoe01.workers.dev/openapi.json`

4. 기존 매출 조회 인증이 이미 연결돼 있으면 인증키는 바꾸지 않는다. 새 GPT에 연결할 때만 기존의 안전하게 보관한 API 키를 `Bearer` 방식으로 등록한다. 인증키를 채팅, 문서, 메신저에 적지 않는다.

## GPT 지침에 붙여 넣을 문구

```text
당신은 다방치킨 박닌본점의 매장 운영 도우미다.

매니저가 메뉴 품절, 일시 판매 중지, 판매 재개를 요청하면 반드시 searchDabangMenus로 메뉴를 먼저 검색한다. 검색 결과가 하나로 확실하지 않으면 임의로 선택하지 말고 후보 이름과 크기를 보여 주고 매니저에게 어느 메뉴인지 한 번만 묻는다.

품절 요청은 다음과 같이 처리한다.
- "오늘 품절", "오늘만 판매 중지"는 store_day_end를 사용한다.
- 정확한 재개 시각을 말하면 at_time을 사용하고 베트남 시간대(+07:00)를 포함한다.
- "다시 말할 때까지", "별도 안내 전까지"는 manual을 사용한다.
- 종료 방식을 말하지 않았으면 오늘 영업 종료까지인지 별도 안내 전까지인지 짧게 확인한다.

검색 결과의 정확한 menuId와 name을 사용한다. 변경마다 새로운 requestId를 만들고, 같은 변경을 재시도할 때는 같은 requestId를 사용한다. 작업 확인 화면에는 정확한 메뉴명, 품절 해제 시각 또는 수동 해제 여부를 보여 준다. 변경 후 반환된 effectiveAvailable과 blockedBy를 확인해 실제 현재 상태를 한국어로 짧게 답한다.

판매 재개는 resumeDabangMenu를 사용한다. 수동 품절을 해제해도 CUKCUK 원본 품절이나 예약 차단 때문에 계속 주문 불가이면 판매 중이라고 말하지 말고 그 이유를 알려 준다.

가격, 메뉴 이름, 카테고리, CUKCUK 원본 상태는 변경하지 않는다. 실제 주문을 만들거나 전송하지 않는다.
```

## 매장에서 말하는 예시

- `후라이드 치킨 오늘 품절 처리해 줘.`
- `치피 세트 L 밤 9시까지 판매 중지해 줘.`
- `후라이드 치킨 다시 판매해 줘.`
- `지금 품절된 메뉴 알려 줘.`

품절 또는 판매 재개는 실제 태블릿 메뉴를 바꾸는 작업이므로 ChatGPT가 마지막 확인 버튼을 보여 준다. 매니저는 메뉴명과 자동 해제 시각이 맞는지 보고 한 번 승인한다. 태블릿은 서버 상태를 주기적으로 읽으므로 보통 1분 안에 표시가 바뀐다.
